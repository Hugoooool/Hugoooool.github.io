一、UR5正运动学#

1.1 DH法#

DH参数在很多文章中都有介绍，本文就不再赘述了，这里只给出结果。 机械臂的关节坐标系如下： 图1.1 机械臂关节坐标系

DH参数如下： 图1.2 机械臂DH参数

其中参数值具体为： $$ d_{1}=0.089159, d_{4}=0.10915, d_{5}=0.09465 d_{6}=0.0823, a_{2}=0.425, a_{3}=0.39225 $$ 有了DH参数，求解正运动学就变得很简单了，相邻坐标系之间的变换关系如下： $$ ^{i-1}T_{i}=\begin{bmatrix} \cos\theta_{i} & -\sin\theta_{i}\cos\alpha_{i} & \sin\theta_{i}\sin\alpha_{i} & a_{i}\cos\theta_{i} \\ \sin\theta_{i} & \cos\theta_{i}\cos\alpha_{i} & -\cos\theta_{i}\sin\alpha_{i} & a_{i}\sin\theta_{i} \\ 0 & \sin\alpha_{i} & \cos\alpha_{i} & d_{i} \\ 0 & 0 & 0 & 1 \end{bmatrix} $$ 正运动学解就是： $$ ^0T_{7}=^0T_{1}^1T_{2}^2T_{3}^3T_{4}^4T_{5}^5T_{6}^6T_{7} $$ 代码如下：

HomogeneousMatrix UR5_Kinematics::computeTransform(const DHParams& dh, const double qi)
{
    double ct = cos(dh.theta);
    double st = sin(dh.theta);
    double ca = cos(dh.alpha);
    double sa = sin(dh.alpha);

    HomogeneousMatrix T;
    T << ct, -st * ca, st * sa, dh.a * ct,
        st, ct * ca, -ct * sa, dh.a* st,
        0, sa, ca, dh.d,
        0, 0, 0, 1;
    return T;
}
HomogeneousMatrix UR5_Kinematics::fk_dh(const JointsVector& q)
{
    HomogeneousMatrix T_total = HomogeneousMatrix::Identity();
    for (size_t i = 0; i < dh_params.size(); ++i)
    {
        dh_params[i].theta = q[i];
        T_total = T_total * computeTransform(dh_params[i], q[i]);
    }
    return T_total;
}

1.2 旋量（PoE）法#

DH法依赖局部坐标系，建立坐标系的方法不同得到的参数就不一样。用旋量法来描述机械臂就不依赖局部坐标系，它的核心思想是：在基座固定坐标系下，把每个关节的运动看成绕某条螺旋轴的旋转/平移，用矩阵指数描述单关节运动，再按顺序连乘得到末端位姿。

首先确定零位，即当各关节角度都为0时，机械臂末端相对于基坐标的位姿矩阵，UR5机械臂的零位矩阵为： $$ T=\begin{bmatrix} 1 & 0 & 0 & -(a_{2}+a_{3}) \\ 0 & 0 & -1 & -(d_{4}+d_{6}) \\ 0 & 1 & 0 & d_{1}-d_{5} \\ 0 & 0 & 0 & 1 \end{bmatrix} $$ 然后确定每个关节对应的旋量轴如图1.1所示。

取各轴线上一点在基坐标系下的坐标： 图1.3 轴线上一点在基坐标系下的坐标

在基坐标系下取关节轴单位旋转方向$\omega_{i}$（转动关节）或设$\omega_{i}=0$（移动关节），并计算线速度部分$v_{i}=-\omega_{i}\times q_{i}$（转动关节）或$v_{i}=$平移方向单位向量（移动关节）。得到旋量参数如下： 图1.4 旋量参数

从而得到空间旋量： $$\xi_{i}=\begin{bmatrix} \omega_{i} \\ v_{i} \end{bmatrix}$$ $T_{0}$和$\xi_{i}$就是旋量法所需要的全部参数。

正运动学方程为： $$T(\theta)=e^{[\xi_{1}]\theta_{1}}e^{[\xi_{2}]\theta_{2}}\dots e^{[\xi_{n}]\theta_{n}}T_{0}$$ 代码如下：

HomogeneousMatrix UR5_Kinematics::fk_poe(const JointsVector& q)
{
    Eigen::Matrix4d T = Eigen::Matrix4d::Identity();
    for (int i = 0; i < NUM_JOINTS; ++i)
    {
        Eigen::Matrix4d T_temp = Eigen::Matrix4d::Identity();
        Eigen::Matrix<double, 3, 1> omega = screws[i].block(0, 0, 3, 1);
        Eigen::Matrix<double, 3, 1> vel = screws[i].block(3, 0, 3, 1);
        if (std::abs(q[i]) < 1e-10) // 处理小角度情况
        {
            T_temp = Eigen::Matrix4d::Identity();
        }
        else
        {
            double sin_theta = sin(q[i]);
            double one_minus_cos = 1 - cos(q[i]);
            Eigen::Matrix3d W;
            W << 0, -omega[2], omega[1],
                omega[2], 0, -omega[0],
                -omega[1], omega[0], 0;

            // 旋转部分
            Eigen::Matrix3d R = Eigen::Matrix3d::Identity() +
                sin_theta * W + one_minus_cos * W * W;

            // 平移部分
            Eigen::Matrix3d V = Eigen::Matrix3d::Identity() * q[i] + one_minus_cos *
                W + (q[i] - sin_theta) * W * W;
            Eigen::Matrix<double, 3, 1> t = V * vel;

            T_temp.block(0, 0, 3, 3) = R;
            T_temp.block(0, 3, 3, 1) = t;
        }
        T *= T_temp;
    }
    T *= M_zero;
    return T;
}

二、UR5逆运动学#

2.1 解析解法#

已知机械臂末端位姿T求各关节角度。

将T写成： $$ T=\begin{bmatrix} n_{x} & o_{x} & a_{x} & p_{x} \\ n_{y} & o_{y} & a_{y} & p_{y} \\ n_{z} & o_{z} & a_{z} & p_{z} \\ 0 & 0 & 0 & 1 \end{bmatrix} $$ 求关节1角度： $$ \theta_{1}=atan2(m_{1}, n_{1})-atan2(d_{4},\pm\sqrt{ c_{1} }) $$ 其中， $$ \begin{aligned} m_{1}&=d_{6}a_{y}-p_{y} \\ n_{1}&=a_{x}d_{6}-p_{x} \\ c_{1}&=m_{1}^2+n_{1}^2-d_{4}^2 \end{aligned} $$ 如果$c_{1}<0$则求解不出来。

如果$c_{1}=0$则表示肩关节处于奇异位置。关节5/6轴线的交点处于Z1Z2平面内，如下图所示： 图2.1 肩关节奇异位置

求关节5角度： $$ \theta_{5}=\pm acos(c_{2}) $$ 其中， $$ c_{2}=a_{x}\sin(\theta_{1})-a_{y}\cos(\theta_{1}) $$ 如果$c_{2}>1$则求解不出来。

求关节6角度： $$ \theta_{6}=atan2(m_{6},n_{6})-atan2(\sin(\theta_{5}),0) $$ 其中， $$ \begin{aligned} m_{6}&=n_{x}\sin(\theta_{1})-n_{y}\cos(\theta_{1}) \\ n_{6}&=o_{x}\sin(\theta_{1})-o_{y}\cos(\theta_{1}) \end{aligned} $$ 如果$\sin(\theta_{5})=0$则表示腕关节处于奇异位置。此时$\theta_{5}=0$轴线Z4和Z6平行逆运动学有无数解，如下图所示： 图2.2 腕关节奇异位置

求关节3角度： $$ \theta_{3}=\pm arccos(\frac{m_{3}^2+n_{3}^2-a_{2}^2-a_{3}^2}{2a_{2}a_{3}}) $$ 其中， $$ \begin{aligned} m_{3}=&d_{5}(\sin(\theta_{6})(n_{x}\cos(\theta_{1})+n_{y}\sin(\theta_{1}))+\cos(\theta_{6})(o_{x}\cos(\theta_{1})+o_{y}\sin(\theta_{1}))) \\ &-d_{6}(a_{x}\cos(\theta_{1})+a_{y}\sin(\theta_{1}))+p_{x}\cos(\theta_{1})+p_{y}\sin(\theta_{1}) \end{aligned} $$ $$ n_{3}=p_{z}-d_{1}-a_{z}d_{6}+d_{5}(o_{z}\cos(\theta_{6})+n{z}\sin(\theta_{6})) $$ 另外需要判断一个条件： $$ c_{3}=m_{3}^2+n_{3}^2-(a_{2}+a_{3})^2 $$当$c_{3}>0$时求解不出来。

当$c_{3}=0$时出现肘关节奇异位置，关节234的轴线共面： 图2.3 肘关节奇异位置

求关节2角度： $$ \theta_{2}=atan2(\frac{(a_{3}\cos(\theta_{3})+a_{2})*n_{3}-a_{3}\sin(\theta_{3})m_{3}}{a_{2}^2+a_{3}^2+2a_{2}a_{3}\cos(\theta_{3})},\frac{m_{3}+a_{3}\sin(\theta_{3})\sin(\theta_{2})}{a_{3}\cos(\theta_{3})+a_{2}}) $$ 求关节4角度： $$ \begin{aligned} \theta_{4}=atan2(&-\sin(\theta_{6})(n_{x}\cos(\theta_{1})+n_{y}\sin(\theta_{1}))-\cos(\theta_{6})(o_{x}\cos(\theta_{1})+o_{y}\sin(\theta_{1})),\\ &o_{z}\cos(\theta_{6})+n_{z}\sin(\theta_{6}))-\theta_{2}-\theta_{3} \end{aligned} $$ 可以看出总共有8组解，求解所有8组解的代码如下：

void UR5_Kinematics::ik_all(const HomogeneousMatrix pose)
{
    for (int t = 0; t < ik_num; t++)
    {
        ik_results[t].state = true;
    }

    double nx = pose(0, 0);
    double ny = pose(1, 0);
    double nz = pose(2, 0);
    double ox = pose(0, 1);
    double oy = pose(1, 1);
    double oz = pose(2, 1);
    double ax = pose(0, 2);
    double ay = pose(1, 2);
    double az = pose(2, 2);
    double px = pose(0, 3);
    double py = pose(1, 3);
    double pz = pose(2, 3);

    double D1 = dh_params[0].d;
    double D4 = dh_params[3].d;
    double D5 = dh_params[4].d;
    double D6 = dh_params[5].d;
    double A2 = dh_params[1].a;
    double A3 = dh_params[2].a;

    double m1 = D6 * ay - py;
    double n1 = ax * D6 - px;
    double condition_1 = pow(m1, 2) + pow(n1, 2) - pow(D4, 2);
    if (condition_1 < 0) // 超出边界范围，求解不出来
    {
        if (printErrorMsg)
            std::cout << "超出边界范围，求解不出来" << std::endl;
        for (int t = 0; t < ik_num; t++)
        {
            ik_results[t].state = false;
        }
        return;
    }
    if (condition_1 < tol) // condition_1 == 0 肩部奇异位置
    {
        if (printErrorMsg)
            std::cout << "肩部奇异位置" << std::endl;
        for (int t = 0; t < ik_num; t++)
        {
            ik_results[t].state = false;
        }
        return;
    }
    double theta1_1 = atan2(m1, n1) - atan2(D4, sqrt(condition_1));
    double theta1_2 = atan2(m1, n1) - atan2(D4, -sqrt(condition_1));
    double theta1[2] = { theta1_1, theta1_2 };
    for (int i = 0; i < 2; i++)
    {
        double c1 = cos(theta1[i]);
        double s1 = sin(theta1[i]);
        double condition_2 = ax * s1 - ay * c1;
        if (condition_2 > 1) // 超出边界范围，求解不出来
        {
            if (printErrorMsg)
                std::cout << "超出边界范围，求解不出来" << std::endl;
            for (int t = 4 * i; t <= 4 * i + 3; t++)
            {
                ik_results[t].state = false;
            }
        }
        double theta5_1 = acos(condition_2);
        double theta5_2 = -acos(condition_2);
        double theta5[2] = { theta5_1, theta5_2 };
        for (int j = 0; j < 2; j++)
        {
            double s5 = sin(theta5[j]);
            if (abs(s5) < tol) // s5 == 0 腕部奇异位置
            {
                if (printErrorMsg)
                    std::cout << "腕部奇异位置" << std::endl;
                for (int t = 4 * i + 2 * j; t <= 4 * i + 2 * j + 1; t++)
                {
                    ik_results[t].state = false;
                }
            }
            double m6 = nx * s1 - ny * c1;
            double n6 = ox * s1 - oy * c1;
            double theta6 = atan2(m6, n6) - atan2(s5, 0);

            double s6 = sin(theta6);
            double c6 = cos(theta6);
            double m3 = D5 * (s6 * (nx * c1 + ny * s1) + c6 * (ox * c1 + oy * s1)) - D6 * (ax * c1 + ay * s1) + px * c1 + py * s1;
            double n3 = pz - D1 - az * D6 + D5 * (oz * c6 + nz * s6);
            double condition_3 = pow(m3, 2) + pow(n3, 2) - pow(A2 + A3, 2);
            if (condition_3 > 0) // 超出边界范围，求解不出来
            {
                if (printErrorMsg)
                    std::cout << "超出边界范围，求解不出来" << std::endl;
                for (int t = 4 * i + 2 * j; t <= 4 * i + 2 * j + 1; t++)
                {
                    ik_results[t].state = false;
                }
            }
            else if (condition_3 > -tol) // condition_3 == 0 肘部奇异位置
            {
                if (printErrorMsg)
                    std::cout << "肘部奇异位置" << std::endl;
                for (int t = 4 * i + 2 * j; t <= 4 * i + 2 * j + 1; t++)
                {
                    ik_results[t].state = false;
                }
            }
            double cos_theta3 = (pow(m3, 2) + pow(n3, 2) - pow(A2, 2) - pow(A3, 2)) / (2 * A2 * A3);
            double theta3_1 = acos(cos_theta3);
            double theta3_2 = -acos(cos_theta3);
            double theta3[2] = { theta3_1, theta3_2 };
            for (int k = 0; k < 2; k++)
            {
                double s3 = sin(theta3[k]);
                double c3 = cos(theta3[k]);
                double s2 = ((A3 * c3 + A2) * n3 - A3 * s3 * m3) / (pow(A2, 2) + pow(A3, 2) + 2 * A2 * A3 * c3);
                double c2 = (m3 + A3 * s3 * s2) / (A3 * c3 + A2);
                double theta2 = atan2(s2, c2);
                double theta4 = atan2(-s6 * (nx * c1 + ny * s1) - c6 * (ox * c1 + oy * s1), oz * c6 + nz * s6) - theta2 - theta3[k];

                ik_results[4 * i + 2 * j + k].joints[0] = theta1[i];
                ik_results[4 * i + 2 * j + k].joints[1] = theta2;
                ik_results[4 * i + 2 * j + k].joints[2] = theta3[k];
                ik_results[4 * i + 2 * j + k].joints[3] = theta4;
                ik_results[4 * i + 2 * j + k].joints[4] = theta5[j];
                ik_results[4 * i + 2 * j + k].joints[5] = theta6;
            }
        }
    }
}

需要通过某种策略从8组解中选择最合适的解，这里给一个与当前角度最接近的选解函数代码如下：

JointsVector UR5_Kinematics::selectBestSolutionStrict(const std::vector<JointsVector> q_list, const JointsVector q_last)
{
    JointsVector best;
    double minCost = std::numeric_limits<double>::max();

    JointsVector q_ref;
    for (int i = 0; i < 6; ++i)
        q_ref[i] = normalizeAngle(q_last[i]);

    for (const auto& sol : q_list)
    {
        double cost = 0.0;
        for (int i = 0; i < 6; ++i)
        {
            double d = normalizeAngle(sol[i] - q_ref[i]);
            cost += JOINT_WEIGHT[i] * d * d;
        }

        if (cost < minCost)
        {
            minCost = cost;
            best = sol;
        }
    }
    return best;
}

综合一下上述求解和选解过程，完整的解析法逆解函数如下：

bool UR5_Kinematics::ik_analy(const HomogeneousMatrix pose, JointsVector& q_result, const JointsVector q_last)
{
    // 1. 计算出所有可行解
    ik_all(pose);

    // 2. 筛选出没有报错的计算结果
    std::vector<JointsVector> q_list;
    for (int i = 0; i < ik_results.size(); i++)
    {
        if (ik_results[i].state == true)
        {
            q_list.push_back(ik_results[i].joints);
        }
    }
    if (q_list.size() == 0) // 如果所有解都计算出错则返回false
        return false;

    // 3. 用选解器找到最合适的解
    q_result = selectBestSolutionStrict(q_list, q_last);
    return true;
}

2.2 数值解法#

由上述求解过程可以看出，有许多条件需要判断，容易出现求解不出来或奇异位置等情况导致求解失败。如果不想出现过多的这种求解失败的情况，可以考虑数值解法。

逆运动学的本质是给定末端位姿： $$ T_{target}\in SE(3) $$ 求关节角： $$ q=[q_{1},q_{2},\dots,q_{6}]^T $$ 使得： $$ T_{fk}(q)\approx T_{target} $$ 即理想情况下$E(q)=T_{target}^{-1}T_{fk}(q)=I$是单位阵。优化目标就是让$E(q)=I$，$\log(I)=0$，所以代价函数可以设计为： $$ J=\parallel \log(E(q))\parallel^2=\parallel \log(T_{target}^{-1}T_{fk}(q))\parallel^2 $$ 迭代的步骤为：

  • 对给定的q进行正运动学求解得到$T_{fk}(q)$；
  • 计算代价函数J；
  • 如果J小于某个给定精度（如$10^{-4}$），则q为优化结果。否则更新q继续上述迭代步骤。

使用Sophus+Ceres库，首先定义残差的计算方式：

/// <summary>
/// ur5逆解残差，用DH计算正解
/// </summary>
struct ur5_IKCostFunctor_DH
{
    ur5_IKCostFunctor_DH(const Sophus::SE3d& T) : T_goal(T) {}

    template <typename T>
    bool operator()(const T* const q_ptr, T* residual) const
    {
        Eigen::Map<const Eigen::Matrix<T, 6, 1>> q(q_ptr);
        Eigen::Matrix<T, 4, 4> T_total = Eigen::Matrix<T, 4, 4>::Identity();
        for (size_t i = 0; i < ur5_dh.size(); ++i)
        {
            T d = ur5_dh[i].cast<T>()[0];
            T a = ur5_dh[i].cast<T>()[1];
            T alpha = ur5_dh[i].cast<T>()[2];
            T ct = cos(q[i]);
            T st = sin(q[i]);
            T ca = cos(alpha);
            T sa = sin(alpha);
            Eigen::Matrix<T, 4, 4> T_temp = Eigen::Matrix<T, 4, 4>::Identity();
            T_temp << ct, -st * ca, st* sa, a* ct,
                st, ct* ca, -ct * sa, a* st,
                T(0), sa, ca, d,
                T(0), T(0), T(0), T(1);
            T_total = T_total * T_temp;
        }
        Sophus::SE3<T> T_now(T_total);

        // 6维残差
        Sophus::SE3<T> T_goal_T = T_goal.cast<T>();
        Sophus::SE3<T> err = T_goal_T.inverse() * T_now;
        Eigen::Map<Eigen::Matrix<T, 6, 1>> res(residual);
        res = err.log();
        return true;
    }
private:
    Sophus::SE3d T_goal;
    const double d1 = 0.089159;
    const double a2 = 0.425;
    const double a3 = 0.39225;
    const double d4 = 0.10915;
    const double d5 = 0.09465;
    const double d6 = 0.0823;
    // ur5的DH参数d,a,alpha
    std::vector<Eigen::Matrix<double, 3, 1>> ur5_dh = {
        (Eigen::Matrix<double, 3, 1>() << d1, 0.0, M_PI / 2.0).finished(),
        (Eigen::Matrix<double, 3, 1>() << 0.0, -a2, 0).finished(),
        (Eigen::Matrix<double, 3, 1>() << 0.0, -a3, 0).finished(),
        (Eigen::Matrix<double, 3, 1>() << d4, 0.0, M_PI / 2.0).finished(),
        (Eigen::Matrix<double, 3, 1>() << d5, 0.0, -M_PI / 2.0).finished(),
        (Eigen::Matrix<double, 3, 1>() << d6, 0.0, 0).finished()
    };
};

也可以用旋量法计算正解：

/// <summary>
/// UR5逆解残差，用poe法计算正解
/// </summary>
struct ur5_IKCostFunctor_poe
{
    ur5_IKCostFunctor_poe(const Sophus::SE3d& T) : T_goal(T) {}

    template <typename T>
    bool operator()(const T* const q_ptr, T* residual) const
    {
        Eigen::Map<const Eigen::Matrix<T, 6, 1>> q(q_ptr);
        Sophus::SE3<T> T_now;
        for (int i = 0; i < 6; ++i)
        {
            Sophus::SE3<T> T_temp;
            Eigen::Matrix<T, 3, 1> omega = ur5_screws[i].cast<T>().block(0, 0, 3, 1);
            Eigen::Matrix<T, 3, 1> vel = ur5_screws[i].cast<T>().block(3, 0, 3, 1);
            T sin_theta = sin(q[i]);
            T one_minus_cos = T(1) - cos(q[i]);
            Eigen::Matrix<T, 3, 3> W;
            W << T(0), -omega[2], omega[1],
                omega[2], T(0), -omega[0],
                -omega[1], omega[0], T(0);
            // 旋转部分
            Eigen::Matrix<T, 3, 3> R = Eigen::Matrix<T, 3, 3>::Identity() +
                sin_theta * W + one_minus_cos * W * W;
            // 平移部分
            Eigen::Matrix<T, 3, 1> t = (Eigen::Matrix<T, 3, 3>::Identity() * q[i] + one_minus_cos *
                W + (q[i] - sin_theta) * W * W) * vel;
            T_temp = Sophus::SE3<T>(R, t);
            T_now *= T_temp;
        }
        T_now *= Sophus::SE3<T>(M.cast<T>());

        // 6维残差
        Sophus::SE3<T> T_goal_T = T_goal.cast<T>();
        Sophus::SE3<T> err = T_goal_T.inverse() * T_now;
        Eigen::Map<Eigen::Matrix<T, 6, 1>> res(residual);
        res = err.log();
        return true;
    }
private:
    const double d1 = 0.089159;
    const double a2 = 0.425;
    const double a3 = 0.39225;
    const double d4 = 0.10915;
    const double d5 = 0.09465;
    const double d6 = 0.0823;
    Sophus::SE3d T_goal;
    // ur5 的旋量参数
    const std::vector<Eigen::Matrix<double, 6, 1>> ur5_screws = {
        (Eigen::Matrix<double, 6, 1>() << 0, 0, 1, 0, 0, 0).finished(),      // joint1
        (Eigen::Matrix<double, 6, 1>() << 0, -1, 0, d1, 0, 0).finished(),    // joint2
        (Eigen::Matrix<double, 6, 1>() << 0, -1, 0, d1, 0, a2).finished(),       // joint3
        (Eigen::Matrix<double, 6, 1>() << 0, -1, 0, d1, 0, a2 + a3).finished(),  // joint4
        (Eigen::Matrix<double, 6, 1>() << 0, 0, -1, d4, -(a2 + a3), 0).finished(),      // joint5
        (Eigen::Matrix<double, 6, 1>() << 0, -1, 0, d1 - d5, 0, a2 + a3).finished()     // joint6
    };
    // ur5 末端初始位姿（零关节角时的T）
    const Eigen::Matrix4d M = (Eigen::Matrix4d() <<
        1, 0, 0, -(a2 + a3),
        0, 0, -1, -(d4 + d6),
        0, 1, 0, d1 - d5,
        0, 0, 0, 1).finished();
};

计算逆解的函数就可以写成如下的形式：

void ur5_ik_ceres(const Eigen::Matrix4d t_goal, Eigen::Matrix<double, 6, 1>& q,
    const Eigen::Matrix<double, 6, 1>& q_init)
{
    Sophus::SE3d T_goal(t_goal);
    Eigen::Matrix<double, 6, 1> q_opt = q_init;

    ceres::Problem problem;

    // 代价：位姿误差
    ceres::CostFunction* cost = new ceres::AutoDiffCostFunction<ur5_IKCostFunctor_DH, 6, 6>(new ur5_IKCostFunctor_DH(T_goal));
    problem.AddResidualBlock(cost, nullptr, q_opt.data());

    // 关节限位
    const std::vector<std::pair<double, double>> joint_limits = {
    {-180, 180}, {-180, 180}, {-180, 180}, {-180, 180}, {-180, 180}, {-180, 180} };
    for (int i = 0; i < joint_limits.size(); ++i) {
        problem.SetParameterLowerBound(q_opt.data(), i, joint_limits[i].first * M_PI / 180.0);
        problem.SetParameterUpperBound(q_opt.data(), i, joint_limits[i].second * M_PI / 180.0);
    }

    ceres::Solver::Options options;
    options.linear_solver_type = ceres::DENSE_QR;
    options.minimizer_progress_to_stdout = false;
    ceres::Solver::Summary sum;
    ceres::Solve(options, &problem, &sum);

    q = q_opt;
}
